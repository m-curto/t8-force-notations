# T8 Force Notations

<!-- <img align=center src=""> -->
because i can't bear it anymore

Changes the button notation.

Downloading the T8 Force Notations will make a similar buttons mapping, then when it's configured, will cook a folder with desired notations.

1. Run T8ForceNotations.
2. Copy your input.
3. Choose a corresponding notation that replaces the visual button.
4. Select which player.
5. Build the Keyboard Layout.
6. Move KBL folder to TEKKEN 8\Polaris\Content\Paks\Mods\KBL

## Notes
1. At the moment, T8FN can't delete any file. So there will be duplicates everywhere. It's highly adviced to delete KBL before build.
